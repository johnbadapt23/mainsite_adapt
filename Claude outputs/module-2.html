{# Module: Quadrant chart Reference: the "Measure how well your organisation adapts to change..." section on go.adapt.com.au/nimble-diagnostics (markup classes nd-mx / nd-mx__y / nd-mx__x / nd-mx__grid / nd-mx__q / nd-mx__name / nd-mx__desc), a 2x2 matrix with a vertical axis label (rotated, reading bottom-to-top), a horizontal axis label, and four fixed quadrant cells. No existing WordPress theme component does a quadrant/matrix chart (the closest, _comparison-module.php, is a text/image comparison table, and _numbers-map.php is a stat row over a background image), so this is a bespoke build, modelled directly on the live markup/CSS above. The four quadrants are a repeater (module.quadrants, exactly 4 items), each with its own Position field (top-left/top-right/bottom-left/ bottom-right) rather than fixed per-corner fields -- positioning is done with named CSS grid-areas keyed off that field, not loop order, so entries can be reordered in the editor without moving where they render. Colour is still fixed per position in this module's CSS, not an editable field, since it carries meaning on this chart (measured from the live page: top-right, the strongest quadrant on both axes, is solid brand red with white text; bottom-left, the weakest, is the lightest cell). Heading uses the same "bold for red text" convention as the rest of this page's headings (and the WordPress theme's own wysiwyg titles), so it's richtext with only bold enabled, output unescaped -- the is what turns red, via this module's own CSS. Escaping: axis labels and quadrant name/description are plain text, output with |escape_html. The figure's aria-label is assembled from the field values, so it's escaped as a whole with |escape_attr. #}
